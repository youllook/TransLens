# TransLens 全域自訂翻譯 prompt
#
# 這裡寫的東西會接在內建的翻譯規定後面，用來調整譯文的「風格」。
# OCR 翻譯與 🎧 音訊字幕都會讀（只在翻譯來源＝本地 LLM 時生效，
# Google 端點沒有 prompt 可以給）。
#
# 用記事本編輯，存成 UTF-8。`#` 開頭是註解，不會送給模型。
# 這份預設「整份都是註解」＝沒有任何額外要求，跟沒放這個檔一樣。
# 要用就把下面某幾行前面的 # 拿掉。
#
# config.json 的 prompt_mode 決定怎麼用這份：
#   append（預設）  接在內建的風格規定後面，且優先於它
#   replace         整段取代內建的風格規定（「只輸出譯文本身」那段格式規定仍保留）
#
# ---------------------------------------------------------------------------
# 寫法建議：與其寫規則，不如給範例
# ---------------------------------------------------------------------------
# 本地跑的 7B 模型對「範例」的服從度，明顯高於對「規則」的服從度。
# 「語氣輕鬆一點」這種抽象要求它常常照舊，但你給它兩三行
# 「原文 → 你想要的譯法」，它就會跟著模仿。
#
# 效果比較差：  語氣要輕鬆口語。
# 效果比較好：  そうですね → 對啊
#               すごいですね → 也太猛了吧
#
# 詞彙表（人名、地名怎麼翻）請寫在 glossary.txt，不要寫在這裡。
#
# ---------------------------------------------------------------------------
# 常用的幾條（拿掉 # 就生效）
# ---------------------------------------------------------------------------

# 不要用「您」，一律用「你」。
# 語氣輕鬆口語，像朋友在聊天，不要像新聞稿或說明書。
# 人名、店名保留原文或音譯，不要意譯。

# 照這個風格翻：
# そうですね → 對啊
# なるほど → 原來如此
# めっちゃ美味しい → 有夠好吃
