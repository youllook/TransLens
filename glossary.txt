# TransLens 全域詞彙表
#
# 這是給「所有翻譯」都套用的替詞表，OCR 翻譯與 🎧 音訊字幕都會讀。
# 只想對某個場合生效的話（例如某個遊戲專用的人名表），另外存一份，
# 用 ⚙ → 詞彙表／自訂 prompt → 額外詞彙表 指定它，兩份會合併，額外那份優先。
#
# 用記事本編輯就好，存成 UTF-8。`#` 開頭是註解，空行會被忽略。
# 全形等號（＝）和前後空白都吃得下。
#
# ---------------------------------------------------------------------------
# 兩種寫法
# ---------------------------------------------------------------------------
#
#   原文 = 譯文          「對照詞」。同時做三件事：
#                        左邊餵給 whisper 當提示詞（讓它比較可能聽對這個詞），
#                        整條組成詞彙表附進翻譯用的 prompt（讓 LLM 照著翻），
#                        而且只有「這句真的出現過的詞」才會附上去，不浪費 token。
#
#   錯的 => 對的         「取代規則」。翻完之後直接對譯文做字串取代。
#                        這是唯一保證會生效的一層 —— 上面那種只是「提示」，
#                        模型可能不聽話，字串取代一定成立。
#
#   [src] 錯 => 對       同上，但套在「原文」上，而且是在翻譯之前套。
#                        whisper 聽錯的詞寫在這裡：先把原文修好，
#                        譯文自然也跟著對了。
#
# ---------------------------------------------------------------------------
# 注意：取代是純字串取代，沒有「整詞比對」
# ---------------------------------------------------------------------------
# 中文與日文沒有空白詞界，做不到只換完整的詞。所以規則寫得越長越安全：
# 「平須 => Hirasu」也會把「平須野」改成「Hirasu野」。
# 同一段文字有多條規則命中時，長的先套。
#
# ---------------------------------------------------------------------------
# 範例（下面都是註解掉的，要用請把 # 拿掉並改成你自己的詞）
# ---------------------------------------------------------------------------

# --- 對照詞：專有名詞怎麼翻 ---
# ひらす = Hirasu
# 鹿せんべい = 鹿仙貝
# 東大寺 = 東大寺

# --- 取代規則：翻錯的詞怎麼救 ---
# 平須 => Hirasu

# --- [src] 規則：whisper 聽錯的詞怎麼救 ---
# [src] 地下せんべい => 鹿せんべい
# [src] 幸福寺 => 興福寺
